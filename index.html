JAGC question shuffler

Draws a random exam set from the question bank, following the selection rule for each booklet. The answer key is encrypted and opens with the grader passphrase.

Question sheet

Press “Shuffle questions” to draw a set.

Answer key

Graders only. Enter the passphrase to decrypt the answer key. It stays unlocked until you close or reload the page.


  






  Selection uses a Fisher–Yates shuffle seeded from crypto.getRandomValues with rejection sampling, so every valid combination is equally likely. The answer key is stored as AES-256-GCM ciphertext and decrypted in your browser; the key is derived with PBKDF2-SHA-256 over 600,000 iterations. Nothing is sent anywhere and nothing is stored between sessions.
